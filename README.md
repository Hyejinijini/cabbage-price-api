# 공공데이터 Open API 기반 배추 가격 데이터 수집 실습

## 1. 프로젝트 소개

공공데이터포털에서 제공하는 한국농수산식품유통공사의
일별 도·소매 가격정보 조회 Open API를 활용하여
2015년부터 2024년까지 서울 가락도매시장의 배추 가격 데이터를 수집하는 프로젝트.

## 2. 수집 대상

- 기간: 2015년 ~ 2024년
- 지역: 서울
- 시장: 가락도매시장
- 품목: 배추
- 등급: 상품
- 구분: 중도매(도매)
- 품종: 봄, 여름(고랭지), 가을, 월동

## 3. 사용 기술

- Python
- Requests
- Pandas
- 공공데이터포털 Open API

## 4. 실행 방법

### 1) 라이브러리 설치

```bash
python3 -m pip install -r requirements.txt
```

### 2) API 인증키 설정

Mac 또는 Linux 터미널에서 다음 명령어를 실행.

```bash
export DATA_API_KEY="본인의_인증키"
```

Windows PowerShell에서는 다음과 같이 설정.

```powershell
$env:DATA_API_KEY="본인의_인증키"
```

인증키는 소스 코드에 직접 입력하거나 GitHub에 공개하지 않음.

### 3) 프로그램 실행

```bash
python3 collect_cabbage.py
```

## 5. 결과 파일

프로그램이 정상적으로 데이터를 수집하면
`cabbage_price_2015_2024.csv` 파일을 생성함.

CSV 파일에는 API에서 반환한 데이터와 수집 연도,
품종명, 품종코드가 포함됨.

## 6. 데이터 출처

- 공공데이터포털
- 한국농수산식품유통공사
- 한국농수산식품유통공사\_일별 도,소매 가격정보 조회

API 안내 페이지:
https://www.data.go.kr/data/15156057/openapi.do

## 7. 유의사항

- API 인증키는 개인별로 발급받아 사용.
- API 응답 및 데이터 건수는 요청 조건에 따라 달라질 수 있음.
- 가격 필드의 단위는 API에서 제공하는 거래 포장 단위를 따름.
